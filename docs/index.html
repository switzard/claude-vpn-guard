Claude VPN Guard

Keep Claude Code and Claude Desktop offline when the tunnel is actually down — pin an exit country, watch session continuity, and freeze incidents mid-flight.

Download v2 GitHub Changelog

What each piece does

Core

Tunnel killswitch

Detects live TUN/adapters across Happ, Hiddify, v2rayN, Clash, Amnezia, WireGuard and more. Claude is suspended or killed while the tunnel is Down or Idle.

Core

Exit location lock

Multi-source geo consensus. Strict mode blocks Claude on the wrong country and shows a clear recovery banner — not a vague “turn on VPN” when the tunnel is already Up.

v2 · Big3

Session Passport

Continuity fingerprint of your exit identity: Stable, Shifted, or Broken. Reanchor when you intentionally change nodes.

v2 · Big3

Incident Freeze Pack

When VPN drops or geo breaks mid-session, Guard freezes a forensic pack. Open incidents live under Incidents — acknowledge when resolved.

v2 · Big3

Guard HUD

Always-on-top strip for passport, VPN, and Claude. Close with × to hide — it does not disable the feature. Tray and Settings stay in sync.

Extras

Toasts · Custom TUN · Profiles

Windows Action Center notifications, sound presets, Custom TUN for long-tail clients, and named killswitch profiles.

Quick start

  1. Download the win-x64 zip from Releases and run ClaudeVpnGuard.exe.
  2. Set your target country and enable Strict location.
  3. Connect a supported VPN client until exit geo matches.
  4. Open Claude Code or Claude Desktop — Guard watches the rest.
